# The Nine Homes — Official Real Estate Website

A premium, modern, high-converting landing page and website for **The Nine Homes**, a residential project located in Punadipadu, near Kankipadu, Vijayawada, Andhra Pradesh.

Designed to generate genuine property enquiries and site-visit bookings while projecting an elegant, trustworthy, family-oriented, and professional brand image.

## 🌟 Key Website Features

1. **Sticky Navigation Bar:**
   * Desktop links: Home, About, Property, Highlights, Location, Gallery, Price, FAQs, Contact.
   * Direct call link `tel:9618896669` and "Book a Site Visit" button.
   * Full-screen smooth slide-out drawer on mobile screens.

2. **Hero Section:**
   * High-resolution architectural exterior visual.
   * Headline: *A HOME WHERE YOUR FAMILY’S DREAMS FIND THEIR PLACE.*
   * Prominent Price Banner: *₹75 Lakhs – Negotiable*.
   * Dual High-converting CTAs: *Book a Site Visit* & *Call 96188 96669*.

3. **Emotional Introduction:**
   * Headline: *MORE THAN A HOUSE. A PLACE TO BUILD YOUR LIFE.*
   * Focuses on family memories, peaceful lifestyle, and the pride of independent ownership.

4. **Property Highlights Visual Grid:**
   * Clean iconography for 168 Sq. Yds, 1325 Sq. Ft, 2 BHK, 2 Bathrooms, East Facing, 100% Vastu, Car Parking, and 40 Ft Road.

5. **Why The Nine Homes:**
   * Structured feature cards detailing privacy, family-friendly layout, vastu compliance, and connectivity advantages.

6. **Location Advantage & Interactive Map:**
   * Interactive Leaflet/OpenStreetMap centered on Punadipadu with custom gold and emerald pins.
   * Clickable landmark cards that dynamically fly to Sri City Venture, Narayana Medical College, Benz Circle, and Kankipadu.

7. **Lifestyle / Family Section:**
   * Headline: *A PEACEFUL PLACE FOR THE MOMENTS THAT MATTER.*
   * High-fidelity residential lifestyle photography depicting family time, peaceful mornings, and green neighborhood avenues.

8. **Filterable Gallery & Modal Lightbox:**
   * Categorized views: Exterior & Road, Living & Kitchen, Bedrooms, Surroundings.
   * High-resolution lightbox modal with keyboard navigation (Esc, Left, Right) and direct site-visit booking link.

9. **Transparent Pricing & Dynamic EMI Calculator:**
   * Detailed price card highlighting land title ownership and negotiable price.
   * Live interactive loan calculator with sliders for Loan Amount (₹20L - ₹75L), Tenure (5 - 30 yrs), and Interest Rate.

10. **Site Visit Booking Form & Confirmation Modal:**
    * Validates full name, 10-digit Indian mobile number, and preferred date.
    * Generates a unique booking reference ID and an instant click-to-confirm WhatsApp button.

11. **FAQ Accordion:**
    * Smooth expand/collapse answers covering price, configuration, plot size, vastu, and booking process.

12. **Mobile-First Optimizations:**
    * Sticky bottom toolbar on mobile: **📞 Call Now | 📍 Book Site Visit**.
    * Floating WhatsApp button with pre-filled message:
      `"Hi, I’m interested in The Nine Homes. I would like to know more details and schedule a site visit."`

13. **Search Engine Optimization (SEO):**
    * Semantic HTML5 elements (`header`, `nav`, `section`, `article`, `footer`).
    * Targeted keywords for Vijayawada, Kankipadu, and Punadipadu real-estate searches.
    * Schema.org `SingleFamilyResidence` JSON-LD structured data for rich search snippet eligibility.

## 🚀 Running Locally

You can preview the website using any standard HTTP server:

```bash
# Using Python
python -m http.server 3000

# Or using Node.js
npm start
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.
